StockMate AI 개인정보처리방침

시행일: 2026년 5월 8일

StockMate AI는 Threads 자동 게시 기능 제공을 위해 사용자가 Meta OAuth를 통해 승인한 Threads 계정 정보와 접근 토큰을 처리합니다. 본 방침은 개발 및 운영 과정에서 처리되는 개인정보와 그 보호 기준을 설명합니다.

1. 수집하는 개인정보 항목

구분 수집 항목
Threads 연동 정보 Threads 사용자 ID, Threads API access token, token 만료 시각, token 갱신 시각
서비스 운영 정보 게시 성공/실패 로그, API 오류 로그, 서비스 진단 로그
문의 정보 이용자가 문의 시 제공하는 이메일 주소 및 문의 내용

2. 개인정보의 이용 목적

  • 사용자가 승인한 Threads 계정에 StockMate AI 콘텐츠를 자동 게시하기 위해 사용합니다.
  • Threads API access token을 갱신하고 게시 권한을 유지하기 위해 사용합니다.
  • 게시 실패, API 오류, token 만료 등 서비스 운영 문제를 확인하고 대응하기 위해 사용합니다.
  • 이용자 문의 및 삭제 요청에 응답하기 위해 사용합니다.

3. 개인정보의 보관 및 파기

Threads 연동 정보는 서비스 제공 기간 동안 보관하며, 이용자가 연동 해제 또는 삭제를 요청하거나 서비스 운영 목적이 종료된 경우 지체 없이 삭제합니다. 운영 로그는 오류 분석 및 보안 점검을 위해 필요한 기간 동안 보관한 뒤 파기합니다.

4. 제3자 제공

StockMate AI는 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 Threads 자동 게시 기능 제공을 위해 Meta Threads API와 통신하며, 이 과정에서 Meta의 API 정책과 개인정보 처리 기준이 적용될 수 있습니다.

5. 개인정보 처리의 위탁

현재 StockMate AI는 Threads 자동 게시 기능 운영을 위해 별도의 개인정보 처리 위탁을 하지 않습니다. 향후 클라우드 호스팅, 결제, 이메일 발송 등 외부 서비스를 이용하게 되는 경우 본 방침을 개정하여 고지합니다.

6. 보안 조치

  • Threads access token은 서버 또는 Redis에 저장하며 외부에 공개하지 않습니다.
  • 서비스 운영에 필요한 최소한의 정보만 처리합니다.
  • 오류 로그에 민감한 token 값이 노출되지 않도록 관리합니다.
  • 운영 환경의 접근 권한을 필요한 담당자로 제한합니다.

7. 이용자의 권리

이용자는 Threads 연동 해제, 관련 정보 삭제, 개인정보 처리 내역 확인을 요청할 수 있습니다. 요청이 접수되면 본인 확인 후 지체 없이 처리합니다.

8. 투자 정보 관련 고지

StockMate AI가 제공하는 정보는 불특정 다수를 대상으로 한 일반적인 투자정보이며, 특정 개인의 투자 목적, 재산 상황, 투자 경험을 고려한 개별 투자자문이 아닙니다. 투자 판단과 책임은 이용자 본인에게 있으며, 금융투자상품은 원금 손실이 발생할 수 있습니다.

10. 방침 변경

본 개인정보처리방침은 법령, 서비스 내용, 운영 정책 변경에 따라 개정될 수 있습니다. 중요한 변경이 있는 경우 서비스 화면 또는 공지 채널을 통해 안내합니다.
